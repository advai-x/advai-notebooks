# 首页插图

[English](README.md)

`training-architecture.png` 是用于文档首页的 AI 生成透明概念插图，表示数据、
训练与可复用模型。它不是科学网络结构图，也不是本项目的功能截图。

Astro 在构建时生成响应式 WebP。仓库 README 原头图
`docs/assets/readme-hero.png` 保持不变。

## 生成提示词

原始英文提示词完整保存在 [English](README.md#generation-prompt) 中，主要要求是：

- 透明背景、4:3 构图，兼容浅色与深色页面。
- 用蓝灰色亚克力数据矩阵、网络层与蓝色模型块表现训练过程。
- 使用克制的蓝色、银色与中性色，柔和工作室光线。
- 不添加文字、代码、标识、UI 截图、机器人或装饰性光晕。
- 明确是概念插图，不声称表达真实科学架构或项目界面。
