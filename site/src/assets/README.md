# Homepage illustration

[简体中文](README.zh-CN.md)

`training-architecture.png` is an AI-generated, transparent concept illustration
for the documentation homepage. It represents data, training and a reusable model;
it is not a scientific network diagram or a screenshot of the project.

Astro generates responsive WebP variants during the site build. The original
repository README banner in `docs/assets/readme-hero.png` remains unchanged.

## Generation prompt

Use case: stylized-concept. Asset type: a text-free transparent hero illustration
for advai-notebooks, an educational machine-learning training guide website.
Create a refined technical still-life: three translucent blue-grey acrylic data
planes with small rectangular matrix cells feed via a few precise blue connections
into a layered compact neural-network structure, then a clean solid blue model
block. Subtle data-to-model progression, not a literal scientific schematic.
Oblique architectural perspective, sophisticated matte materials, crisp edges,
soft studio light and restrained pale blue reflections. Wide 4:3 composition with
all subjects visible, a compact balanced silhouette. Genuine transparent background
so the same illustration works on light and dark web surfaces. One blue accent
only, neutral slate and silver. No words, letters, numbers, logos, UI screens,
code, labels, arrows, humanoid robots, brains, glowing halos, purple, decorative
blobs or watermark. This is a professional technical illustration, not a fake
dashboard screenshot.
