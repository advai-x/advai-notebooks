# VM training guide

[Open the executable tutorial](01_finetune.ipynb) · [Open in Colab](https://colab.research.google.com/github/advai-x/advai-notebooks/blob/main/notebooks/vm/01_finetune.ipynb)

Action-conditioned numerical World Model, native fine-tuning and recursive state rollouts; not a video model.

The tutorial contains executed offline CPU outputs and checks for data validation, training, native reload, inference, epoch recovery and dry-run publication.
Synthetic fixtures and random tiny models do not establish real-world quality.
See the [full guide](../../docs/vm.md) for data contracts and backend limitations.
